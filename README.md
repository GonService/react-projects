# React projects

Front-end projects by [GonService](https://gonserviceit.com.br/software-sob-demanda), built with React
and TypeScript. Each folder is an independent project with its own README and tests; CI checks,
tests and builds every one of them.

| Project | What it shows | Stack |
| --- | --- | --- |
| [support-dashboard](support-dashboard) | Support queue with an SLA deadline timeline, filters and live data from a REST API | React, TypeScript, Vite, Vitest |
| [booking-widget](booking-widget) | Embeddable appointment booking: service, calendar, free slots computed from hours and bookings, validated form | React, TypeScript, Vite, Vitest |
| [kanban-board](kanban-board) | Team task board with drag and drop, keyboard moves, labels, due dates, filters and local persistence | React, TypeScript, Vite, @dnd-kit, Vitest |
| [quote-generator](quote-generator) | Quote (orçamento) builder with line items, discounts, taxes, a printable A4 preview, drafts and JSON export | React, TypeScript, Vite, Vitest |
| [metrics-dashboard](metrics-dashboard) | Infrastructure metrics with KPI tiles, hand-drawn SVG charts, service health and optional Prometheus data | React, TypeScript, Vite, Vitest |
